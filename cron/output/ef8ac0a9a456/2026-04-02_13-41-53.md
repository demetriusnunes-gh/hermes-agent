Ignore: newsletters, promotions, social notifications, automated receipts, bulk mail.

## Steps

### 1. Fetch Recent Emails

```bash
himalaya envelope list --output json 2>&1 | timeout 20 cat
```

If JSON fails, fall back to plain format.

Parse the results, keeping only emails from the last 2 hours (or specify timeframe).

### 2. Filter and Read

For each promising email, read its content:

```bash
himalaya message read <id> 2>&1 | head -100
```

### 3. Report

For each relevant email found, report:
- **Sender:** email/name
- **Subject:** full subject line
- **Date:** when received
- **Why it matters:** 1-line reason
- **Summary:** 1-2 lines of content if needed

Format:

```
📧 Relevant emails (last 2h):

1. Fernanda (fhamacher@gmail.com)
   Subject: Dinner Friday?
   11:42 AM — Just checking about dinner plans
   → Needs a reply

2. Eleva - Comunicação
   Subject: Reunião de pais - 15/04
   10:15 AM — Parent meeting on April 15th at 7pm
   → Calendar event, mark it

No relevant emails: "No important emails in the last 2 hours."
```

## Tips

- Himilaya can timeout — always add a `timeout` wrapper
- Use `--output json` when possible for easier parsing
- If inbox returns 0 results, email might not be connected — report the error
- Be conservative: only flag what truly needs attention
- If an email is borderline relevant, mention it at the bottom as "maybe check"
