# Static File Publishing Checklist

- [ ] Confirm the source URL, target filename, and intended absolute web root.
- [ ] Download with redirects followed; record a successful exit status.
- [ ] Verify file size, type, and completeness before copying.
- [ ] Confirm the destination is the intended path and readable by the web server.
- [ ] Test the public URL with a HEAD request.
- [ ] Confirm the expected HTTP status, redirect behavior, and content type.
- [ ] Report source, destination, URL, and verification result.
