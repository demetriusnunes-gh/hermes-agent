# 2026-05-12 research notes — Brazil-gap leads and proof snippets

Condensed notes from the 2026-05-12 digest. Use as a seed bank, not a snapshot; re-check pages before citing.

## HN query patterns that produced useful leads
- `skills marketplace AI` → Agensi
- `workflow automation AI` → Open Routines, Soforce
- `pricing AI agent` / `Show HN pricing AI` → Dead Simple Email, Retroguard, PrivateClaw, Statewright
- `proposal generator pricing` / `business proposal AI` → Proposly

## Useful proof snippets
### Agensi — AI agent skills marketplace
- URL: https://www.agensi.io
- Signal: one-time purchase, instant download, SKILL.md marketplace; works with Claude Code, OpenClaw, Codex CLI, Cursor, and 20+ agents.
- Brazil note: strongest local wedge is sellable skills for WhatsApp, Pix, NF-e, Omie/Tiny/Bling, Nuvemshop, VTEX, not a generic global skill bazaar.

### Statewright — agent workflow guardrails
- URL: https://github.com/statewright/statewright
- Signal: pricing tiers on the repo page: Free / Pro / Team / Enterprise; free tier included; self-hostable engine.
- Brazil note: strong fit for PT-BR dev teams shipping agent workflows; local wedge is reliability + run history + guardrails.

### Retroguard — secure AI guardrails
- URL: https://retroguard.ai
- Signal: outcome-based pricing, first 100 blocked requests free, then $2 per 100 blocks; hardware-attested secure execution.
- Brazil note: good fit for regulated teams, but the core offer is infra/devtool-like, so Brazil demand is more B2B than SMB.

### Dead Simple Email — email infrastructure for AI agents
- URL: https://deadsimple.email/
- Signal: purpose-built bidirectional inboxes for AI agents; pricing/docs/integrations; inbound emails arrive as structured JSON via webhooks.
- Brazil note: useful for automation teams, but not an obvious Brazil-first consumer or SMB wedge.

### Proposly — proposal generator
- URL: https://proposly.org
- Signal: `2 free proposals`, `<$1 per proposal`, `30s generation time`, real user testimonials.
- Brazil note: plausible for freelancers/SMBs, but local competition and low ARPU require a narrow niche.

## Market-gap takeaway
The most repeatable pattern in this session was: start from a product with visible pricing or HN traction, then ask whether Brazil has an obvious incumbent. If the answer is yes, narrow the wedge instead of cloning the US offer.
