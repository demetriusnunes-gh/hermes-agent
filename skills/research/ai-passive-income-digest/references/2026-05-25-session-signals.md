# 2026-05-25 session signals

## HN / launch leads that surfaced
- **Pulse AI** — voice AI for restaurants.
  - Proof signals: active installs count shown on site; ROI calculator; claims around order accuracy and annual labor savings.
  - Brazil gap: restaurant incumbents in Brazil tend to emphasize WhatsApp/chat automation more than missed-call voice automation.
  - Brazil-first wedge: Portuguese missed-call recovery for restaurants with POS integration.

- **Delegare** — payment rail for AI agents.
  - Proof signals: live product + explicit transaction pricing; merchant onboarding path; audited spend/approval framing.
  - Brazil gap: no obvious Brazil-native AI-agent payment layer with Pix/BRL support.
  - Brazil-first wedge: agent spend controls + Pix-compatible merchant/approval flow.

- **Datapace** — Postgres regression detection / database reliability agent.
  - Proof signals: live pricing funnel; GitHub App onboarding; setup-in-minutes positioning.
  - Brazil gap: Brazil has many Postgres-heavy startups, but no obvious local brand around database regression agents.
  - Brazil-first wedge: GitHub App + Postgres telemetry + PR comments for slow-query regressions.

## Useful validation pattern from this run
- Prefer candidates with **two concrete proof signals** (e.g. pricing + HN traction, or live product + customer/ROI claims).
- For Brazil-gap checks, do a fast incumbent scan before calling a market empty; if there is a strong local adjacent incumbent, narrow the wedge rather than cloning the whole product.
- For agent infra ideas, the strongest Brazil-fit questions are usually about **payments, approvals, localization, and workflow wedges** rather than broad platform parity.
