# 2026-05-16 agent/workflow market signals

Session notes for the AI passive income digest.

## New validated examples

### Voker
- Positioning: analytics for AI agents.
- Proof signals seen: live pricing tiers (`$0 / $80 / $400`) and customer testimonial from a recognizable operator.
- Useful wedge lesson: Brazil-first version should be narrow and operational, e.g. WhatsApp/web agent ROI reporting, not a generic observability platform.

### Statewright
- Positioning: visual workflow builder / protocol-level enforcement for AI agents.
- Proof signals seen: Show HN traction, GitHub stars, Free + Pro pricing.
- Useful wedge lesson: protocol-level guardrails are more differentiated than generic agent orchestration.

### AgentPort
- Positioning: security gateway / approval policies / audit logs for agent tool calls.
- Proof signals seen: live Free and Plus pricing, small but real HN signal, public repo.
- Useful wedge lesson: approval/audit gateways are easier to explain than “agent platform” and map well to LGPD-friendly retention controls.

### Agent-data
- Positioning: structured real-time data access for agents.
- Proof signals seen: pricing page with free trial and explicit per-call pricing.
- Useful wedge lesson: explicit per-call economics are valuable when assessing whether a product can be rebuilt locally with low infra cost.

### Operator23
- Positioning: plain-English workflow automation that fixes itself when it breaks.
- Proof signals seen: Show HN exists, but traction is thin compared with pricing/customer evidence on stronger candidates.
- Useful wedge lesson: do not promote a product on language alone; require stronger proof signals before ranking it.

## Research workflow refinements

1. Prefer direct page inspection via `urllib.request`/HTML parsing when browser snapshots omit pricing, customer counts, or other key evidence.
2. Treat GitHub stars as supporting context only; do not use them as the primary traction signal.
3. When a US product looks strong, immediately check adjacent Brazilian incumbents before calling the market underserved.
4. For Brazil-fit decisions, prefer narrow wedges tied to concrete workflows (WhatsApp, calls, approvals, audit logs, clinical intake, leasing, etc.) over broad “agent platform” clones.
